🏥 HomeoCare

A Homeopathy Clinic Management System developed using Django to streamline patient records, appointments, and clinic operations.

🚧 Status: Under Development

✨ Objectives

• Manage patient records efficiently  
• Maintain patient visit history  
• Streamline appointment requests  
• Improve communication between doctors and receptionists  
• Reduce paperwork and manual record keeping  

👥 User Roles

🩺 Doctor

• View patient history  
• Create and update medical records  
• Prescribe medicines  
• Manage treatment records  

🗂️ Receptionist

• Register new patients  
• Manage appointments  
• Maintain patient information  
• Access prescriptions provided by doctors  

🧑‍🤝‍🧑 Patient

• Request appointments online  
• View appointment status  
• Receive appointment notifications  

🌟 Features

• Patient Registration  
• Unique Patient ID System  
• Medical History Tracking  
• Appointment Management  
• Prescription Management  
• Treatment Records  
• Notification System
